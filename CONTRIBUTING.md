# Contributing to SCOUT

Thanks for your interest in improving SCOUT.

## Before contributing

- Open an issue to discuss significant changes.
- Keep contributions focused and easy to review.
- Do not add features intended to bypass authentication, CAPTCHAs, paywalls, robots.txt restrictions, or other access controls.
- Do not add collection of sensitive personal information.
- Never commit generated reports containing personal information, credentials, API keys, or other private data.

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Run the application and relevant checks.
5. Update documentation when behavior changes.
6. Open a pull request describing the problem and solution.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Documentation is updated.
- [ ] No secrets or personal research reports are included.
- [ ] New behavior has appropriate tests, where practical.
- [ ] The change respects the project's responsible-use requirements.
