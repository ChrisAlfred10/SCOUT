# Security Policy

## Scope

SCOUT is an early-stage command-line research tool. It processes search-result URLs and may request public web pages.

## Reporting a vulnerability

Please do not publish exploitable details or personal data in a public issue.

Instead, contact the repository maintainer privately using the contact method listed on the maintainer's GitHub profile. Include:

- A concise description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation, if known

Do not include real people's personal information in reports.

## Safe-use note

Do not use SCOUT to bypass access controls or retrieve private or restricted information. The current implementation is experimental and should not be treated as a hardened security product.
